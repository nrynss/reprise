## What it built

`internal/seed` carries the shared catalog with copy, receipt, and
drop. `data/season/` ships with a readme only, so the catalog starts
empty. The operator adds one JSON file per episode plus optional audio
siblings after first deploy. The file name is the stable key.

Sync imports the directory into catalog rows under the reserved seed
user. It validates every file before it applies any, skips unchanged
hashes, swaps changed entries in one transaction, and retires entries
with no file. Catalog audio persists once as public blobs, because the
bytes are identical demo material for every visitor. Copies hold rows
only: episode, words, mentions, and the planted callback. Copies keep
catalog numbers and set the seeded flag.

EnsureCopy runs on the season list, never in session mint. It skips
owners and the seed user, skips receipt holders, skips users with a
season, and skips empty catalogs without writing receipts. The copy
and its receipt land in one transaction. Drop deletes one visitor copy
rows only and keeps blobs, neighbors, and the receipt. Seeded lists
copies by the flag in one query.

Sixteen tests pin every done clause with generated files only. No
fixture ships. The callback test runs the real memory selector on
copies and opens on the copied Jonas thread in episode 1. The sweep
test runs the guest expiry query shape and proves it skips the seed
user by kind.

## Surprises

The copied planted rows interact with the selector no-repeat rule. The
most recent copied plant blocks its own quote on the next select, so
the fixture plants Maya and asserts the selector falls through to the
second copied thread. This matches spoken history semantics, because
the greeting reads the plant before the next select runs.

Retiring a catalog entry deletes its audio blob. This is safe only
because copies hold no media rows. If a later change gives copies
their own media rows, the retire path must recheck sharing first.

Receipts cascade with swept users through the foreign key. A swept
guest leaves no receipt behind, which is correct because the user row
is gone too.

## Contract changes

Three wiring items live outside the owned paths. The season list must
call Sync and EnsureCopy for the request user. The episode delete
handler must branch on the seeded flag: recorded episodes keep the
erasure fan-out, seeded episodes go through seed Drop. The guest sweep
must use seed Drop for seeded episodes. Erasing a seeded copy through
the fan-out would delete the shared catalog audio for every visitor,
because the copy rows name the catalog blobs. The image must also ship
`data/season` with a copy step, because the Dockerfile currently
carries no data directory.
