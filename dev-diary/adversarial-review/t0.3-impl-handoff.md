directory, so the settings fallback misses the checkout file. The probe
walks up to find it. Second, the credential constructor takes nil
options in one auth version and panics, while the resolved version
needs explicit scopes. Passing the cloud platform scope fixed it.

The stem came out near 19.5 minutes, not a full 20, because Piper
renders faster than wall clock math predicts. The size question is
settled anyway. Inline held with margin, so I stopped there.
