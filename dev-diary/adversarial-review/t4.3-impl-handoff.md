## What it built

every controller. Five fixture episodes reuse the prototype turns with
compact timings. Every thread quote names an episode and an offset
that opens the turn carrying it, and unit tests pin that each quote
sits in its transcript. `GalleryController` follows each rendering
job through the library follower, the same one the processing screen
reads, and renders the high-water mark from browser storage, so a
replayed stream never drags a card backwards across a reload. The mock
job serves scripted progress frames on timers with the stream left
open, the way a long render behaves. `EpisodeController` plays the
generated tone through the library player, seeks words and chapters,
and parks the playhead at a deep link quote. Publish, erase, and
export render their states and degrade to notices, since their actions
belong elsewhere.

cover, title, state, and duration. Rendering cards show a live

for the crawler, so the episode routes build with no extra config.

notes with a transcript that follows playback. Word buttons seek.
Thread links land here with the playhead at the quote.

recurring people, and circled topics as links. Quotes and links only.

## What surprised it

The route lint forbids type annotations, type declarations, and
unions inside component scripts. Only rune generics parse. All typed
logic moved into the owned TypeScript module, and the pages mirror
snapshots with inferred types.

The generated link helper types plain strings as errors, so the quote
link builder returns a template literal type.

Autoplay without a gesture poisons the library unlock and races any
later press. The deep link seeks to the quote and invites the press
instead. The proof clicks once and playback starts at the quote.

A stale preview server on the proof port served an old bundle until
it was killed. Later probes ran clean.
