## What it built

`cmd/reprise/main.go` now loads settings once through `REPRISE_CONFIG` and
logs `Plan.String` at boot. The plan names every source and carries no
value. A missing or unreadable secret stops the process before it listens.
SIGTERM and SIGINT start a drain. A gate refuses `POST /api/sessions` with
a `server_draining` 503 while open sessions run. The drain polls the
session registry through a one method interface that the broker lease
manager already satisfies, bounded by the session cap from settings with an
1800 second fallback. HTTP closes after the drain. `main` passes nil for the
registry because no handler is wired yet. The broker change passes
`broker.Leases()` in with no interface change. Health now answers
`ok <boot> version=<build>`, stamped through `-X main.version` from the
`VERSION` build argument. Tests cover the gate, the drain wait and timeout,
the budget fallback, and a full signaled run against localhost.

`Dockerfile` pins Go 1.27.1, stamps the version, bakes the box settings
file, and copies static `ffmpeg` and `ffprobe` 7.1 into `/usr/local/bin`
from the pinned `mwader/static-ffmpeg:7.1` image. See the surprise below
for why the image replaces the archive URL.

`deploy/run.sh` starts one container on the `proxy` network with no
published port, Traefik labels for `reprise.nryn.dev`, read-only mounts of
`/etc/reprise/env` and `/etc/reprise/gemini-sa.json`, a bind mount of the
host state to `/var/lib/reprise` owned by uid 65532, `--memory 1g`,
`--cpus 1.0`, and `--stop-timeout 1830`. No secret travels on the command
line or through environment flags. A slash in `IMAGE` pulls a registry
reference. A plain tag uses a local image. Both delivery flows share the
script with no mode flag.

`deploy/redeploy.sh` records the running image, starts the target, gates
on the container IP with build match and rollback, then prunes.
`deploy/backup.sh` copies the live database through the SQLite online
backup API, checks the copy, copies media, writes a manifest, and prunes to
seven runs. The destination is a required parameter and the script holds no
credential. `deploy/README.md` documents setup, both delivery flows,
limits, workstation verification, cron, restore, and safety.

## What surprised it

The binary archive CI installs is gone upstream. The repository behind the
`mwader/static-ffmpeg` release URL returns 404, and the renamed
`wader/static-ffmpeg` ships no release binaries. The Dockerfile therefore
copies the pair out of the same author's pinned `mwader/static-ffmpeg:7.1`
image instead. Same author, same version, different carrier. The gate CI
still curls the dead URL, so CI fails at its media install step today. That
file is outside this task, so this task only records it here.

The legacy builder on this machine ignores `COPY --chmod`, so the
Dockerfile relies on the source image modes instead. The pair runs as the
nonroot user, verified by direct run.

The box TOML and the container agree on `/var/lib/reprise` with
`data_dir` and `media_dir` beneath it. The host side defaults to
`/srv/reprise`, so the layout is `/srv/reprise/data` and
`/srv/reprise/media`. The backup default database name is `reprise.db`
until the store names the file. Override with `DB_FILE`.
