## What was built

1. Clock. `take.ts` gains pure `elapsedSeconds(now, start, pausedTotal, pausedSince)` with the spec formula. The record timer renders through it, so the display freezes while paused. First End press records `pausedSince` from the context clock. Cancel accumulates and clears.
2. Mic. While paused, `publishUserBlock` appends same-length zeros to the user stem and sends same-length zeros to the socket. The level meter reports silence.
3. Host. First End press cuts any playing reply through `flushHostStem`. `handleHostAudio` drops incoming audio while paused.
4. Resume. Cancel restores "On air. The host hears you." Confirm ends as before. Paused notice reads "Paused. End this take? Cancel resumes it." Cap timer untouched.
5. Harness. The mock controller exposes clock, paused samples and frames. A wire tap records only `input.audio` frames sent while paused.

## Billable-pause note

The provider connection stays open during the pause, so those seconds still bill. The socket hears only zeros, so no paused speech reaches the host or the episode, but the meter keeps running.
