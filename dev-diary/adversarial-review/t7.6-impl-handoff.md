## What it built

Stem completion drives the recording-to-draft handoff with one
transcript job chained to one editorial job.

New route `POST /api/episodes/{id}/stems/complete` takes the media
pair plus sample rates and returns episode id, moved flag, scheduled
flag, job id, and state. Refusals reuse the shared envelope with
`stems_not_found` and `pipeline_busy` beside existing codes. New
`episode.Service.CompleteStems` links the pair on first call and wins
the draft move. Repeats keep the first pair and report moved false.
Paid kinds keep their non-idempotent registration.

## Surprises

The live pass stores no host word timings and no alignment pass runs
here, so the schedule passes empty host replies and zero offsets.
The merge carries the user timeline the editor cuts against. The
`Unfinished` job query misses jobs that never reported, so the
guards also treat undescribed same-kind jobs as covering. A second
paid job never starts beside a silent first. One privacy resume test
flaked once under load and passed three solo runs with no import
edge to these paths.
