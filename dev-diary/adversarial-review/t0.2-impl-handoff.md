# T0.2 implementation handoff

Probe of the Voice Agent API against live sessions. Final commit on branch
`task/t0.2` in worktree `t0.2-impl`. This file reports the measurements, the
spend, and the contract changes the probe needs.

## What was built

- `internal/assemblyai/live_test.go`: live probe behind the `live` tag. It
  mints tokens through the settings loader, opens raw TLS sockets with hand
  written websocket framing, streams generated PCM at realtime rate, and
  records every event with local clock times. Five sessions: greeting,
  exchange, keyterm pair, and a 60 second cap window. It deletes all five
  and fails when any deleted session still lists.
- `internal/assemblyai/doc.go`: package clause only. A package with live
  tagged test files alone breaks the non-live gate, so this file keeps
  plain `go test` green. Whoever owns the provider adapter keeps it.
- `testdata/speech/`: two espeak-ng clips with the committed `generate.sh`
  that reproduces them in Docker, plus 24 kHz PCM renders beside each wav.
- `dev-diary/probes/voice-agent.md`: the probe record with every raw event
  shape, the ffprobe output, and the spend accounting.
- `dev-diary/project.md`: the session cap fact now records that the cap
  does not end the session by itself.

## What was measured

- Token: single use, strict 422 ranges, `expires_in_seconds` required and
  capped 1 to 600, session cap 60 to 10800. `expires_at` sits one hour out
  for caps 60, 120, and 600 alike.
- Greeting spoken first and unprompted, transcript matches configured text.
- `transcript.user` has text only, no timings. `transcript.agent.delta`
  carries `start_ms` and `end_ms` on every word.
- `session.end` draws `session.ended` at once with connected seconds only.
  `audio_duration_seconds` reads null on every run.
- The 60 second cap does not close the socket. Three runs stayed open past
  100 seconds with the Sessions API reporting created and null duration.
- Recording is stereo Opus with the user left. ffprobe and channel energy
  agree. Metadata states the layout outright.
- DELETE returns 204 and removes all five sessions from the list.
- Keyterms shift the invented name Zaffranil both runs, while unkeyed runs
  guess different near misses. No cloud speech and no real voice anywhere.

## Spend accounting

The final Go run mints five tokens and connects about 110 seconds, near
14 cents at 4.50 dollars per hour. Exploration runs before it brought the
shared key total near 1.02 dollars at count time, beside the parallel
batch probe. Every token caps at 120 seconds or less. All probe sessions
were deleted. The per run budget holds with wide margin.

## Surprises

- The cap finding overturns the plan. The browser needs its own timer and
  must send `session.end` first. The project fact is updated in this commit.
- Raw framing must be exact. A four byte length header on a short message
  reads as length zero and the server closes the socket.
- The peer batch probe owns the same package directory on a sibling branch.
  Both branches carry an identical `doc.go`. Landing second needs a delete
  of the duplicate add. Helpers stay prefixed per probe to avoid collisions.

## Contract changes needed

- `internal/assemblyai` has no owner before T2.1, yet two probes now write
  live tests and a shared `doc.go` inside it. Name an owner now or accept
  that T2.1 inherits both probe files and the package clause.
- The token cap cannot bound a lost session. The 30 second resume window
  and the kill switch carry that load today, plus the client side timer
  the probe record mandates.
