# T7.49 implementer handoff

Commit `8d1f572` on branch `task/t7.49`, worktree `/home/nryn/work/reprise-wt/t7.49-impl`. Only `internal/broker/reconcile.go`, `internal/broker/reconcile_test.go`, and `internal/broker/end_test.go` changed.

## What was built

`ReconcilerConfig` gained `Wait func(ctx context.Context, d time.Duration) error`, stored on `Reconciler`. Nil uses a real timer that returns `ctx.Err()` when the context ends. `settleReadBackoff` of 500 ms, 1 s, 2 s, 4 s, 8 s, 8 s (23.5 s total, inside the 100 s limit). `readForSettle` keeps the first read and the single `StopSocket`, then reads again after each backoff step until success or a non-open error. All-open returns an error wrapping `ErrSessionOpen` and settles nothing, leaving the sweep to settle later. No guessed duration is ever priced.

## Tests

Three new tests behind a `settleDelayReader` fake that stays open for a fixed number of failing reads: N = 2 settles with both artifacts stored, the claim row settled with both media ids, one `StopSocket`, and waits saw 500 ms then 1 s. A never-closing reader returns an error wrapping `ErrSessionOpen`, leaves the row unsettled with the hold untouched, and the waits saw all six steps. A second `Reconcile` on the settled session calls neither `StopSocket` nor `Wait`. `end_test.go` only passes an immediate `Wait` into its existing open-session test. N counts all failing reads including the pre-stop one.

## Validation

`go vet` clean, `gofmt` clean, `go test -race -count=1 ./internal/broker/` passes. Mutation: replacing the loop with a single read fails the first two new tests; restored and green. `./tools/check.sh` stops at the known `FAIL [tools] ffmpeg is 9.0.2, not the pinned 9.0.1`.
