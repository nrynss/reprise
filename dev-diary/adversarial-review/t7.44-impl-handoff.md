# T7.44 implementer handoff

Commit `af4fb8e` stores the speaker with each word. The `words` table gains a `speaker` column through additive migration `0003_words_speaker.sql`. The transcript insert writes the role and the load reads it back. Playback (`EditWord.Speaker`), the editor (`speakerOf` in `draft.ts`), and the editorial timeline (speaker-labelled lines in `validate.go`) read that speaker. A host word never appears as the guest.

## What was built

- `internal/store/migrations/0003_words_speaker.sql`: `ALTER TABLE words ADD COLUMN speaker TEXT NOT NULL DEFAULT ''`. The default keeps every existing raw insert (analysis, seed, older tests) working.
- `internal/transcript/store.go`: `Stored` gains `Role`. `Replace` writes it, `Load` reads it. `Replace` already rejected unknown roles, so an empty role still fails the write.
- `internal/transcript/speaker_test.go`: `TestReplaceKeepsTheSpeaker` merges one host reply beside one guest line, stores, and requires the load to name each speaker, plus a raw column check.
- `internal/episode/playback.go`: `EditWord` gains `Speaker`, read from the new column.
- `internal/episode/speaker_test.go`: `TestEditWordsKeepTheSpeaker` stores through `transcript.Replace` and requires playback to name each speaker.
- `internal/editorial/validate.go`: `word` gains `Speaker`. `timeline` prints `[i] speaker: text (start-end)` when a speaker is stored and keeps the old shape for older rows.
- `web/src/lib/editor/draft.ts`: `readStoredDraft` maps `host` to `host`, `user` or `you` to `you`, and anything else (including missing) to unknown instead of the guest. The old fallback labelled every missing speaker as the guest.
- `web/src/lib/editor/draft.test.ts`: new test pins `host`, `user`, and missing mapping to `host`, `you`, and unknown.

## Surprises

- The new migration breaks one test outside this task's paths. `TestMigrateAppliesTwiceWithNoChange` in `internal/store/store_test.go` pins the ledger to exactly the two old migration files. It now fails with the third file applied. That file is outside owns, so this commit leaves it failing. Every other Go package passes.
- `internal/editorial/run.go` still selects only text and timing in `loadWords`, so the new timeline labels stay dormant until that query reads the column. That file is outside owns too.

## Contract changes needed (outside owns, not touched)

1. `internal/store/store_test.go`: the ledger pin must expect `0003_words_speaker.sql`.
2. `internal/editorial/run.go` `loadWords`: select the `speaker` column into `word.Speaker` so the labelled timeline activates.
3. `internal/api/episodes.go` `wordJSON` and `wordsOf`: forward the speaker on the detail endpoint, or the editor keeps receiving words with no speaker key. The new editor mapping treats a missing key as unknown rather than the guest.
