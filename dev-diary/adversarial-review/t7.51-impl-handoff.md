Commit `fdf0539` on branch `task/t7.51`, worktree `/home/nryn/work/reprise-wt/t7.51-impl`. Only `internal/host/` and `cmd/reprise/main.go` plus `main_test.go` changed.

## What was built

- `internal/host/host.go`: `PriorEpisodes int` on `Input`, filled by `Load` with a count of earlier non-recording episodes. `returningOpener` for owners with history and no callback. `CallbackID string` with `json:"-"` on `Config`, set only when the greeting cites that callback.
- `cmd/reprise/main.go`: `hostBuilder.BuildSessionConfig` calls `memory.MarkUsed` after `host.Load` succeeds when `CallbackID` is set. A failed mark returns the error, so the mint refuses instead of repeating a callback. No `internal/broker/` change.
- Tests: host unit pins for first vs returning opener by count, `CallbackID` on a cited callback, and `Load` with a recording row present. `main_test.go` seeds one owner with two unused callbacks and proves two mints greet differently with both rows used. `TestUsedCallbackIgnoredAndOwnerIsolated` updated to the returning opener.

## Validation

## Recorded loss
