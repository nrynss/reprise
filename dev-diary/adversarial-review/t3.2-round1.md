## Scope notes the brief asked for

(a) Offsets versus word ids. The spec prose says proposals point at word ids.
The implementation points at positional offsets. This reviewer rules it a valid
interpretation, not a violation. The schema predates the task and defines
`start_word` and `end_word` as INTEGER plus `mentions.word_offset`. Word ids are
TEXT minted fresh by every `Replace`, so ids are unstable across reruns while
offsets are stable. `loadWords` uses the same `ORDER BY start_ms ASC, rowid ASC`
as `transcript.Load`, so offsets index `Load` order exactly. The handoff
contracts T3.3 and T3.4 to read offsets into `Load` order. The numbering is
pinned (`[0]` through `[39]` in the timeline assertion, stored `[0, 39]`
checked against the word count). No downstream code assumes row ids, and
`host.Load` already reads mentions by kind and offset. No finding.

(b) The callback stores a `mentions` row of kind `callback` with its word
offset and quote, plus a `callbacks` row with `used = 0`. The next opening can
cite stored data. Invariant 11 holds. Pinned by `TestRunStoresDraft`.

(c) The cold open prompt orders delivery over transcript and carries the rule
the T0.3 listening probe proved. The send shape is pinned (both stems as Opus
parts, timeline present, delivery sentence present, JSON schema attached).
No offline test can reproduce the probe pick itself without fixture sessions
or paid spend. A live agreement remeasure is owed when fixtures land. This is
an observation, not a finding, since no offline pin can measure it.

(d) Forced model failure and unusable JSON both leave a renderable draft with
no cuts and a plain title. Both paths are pinned, including receipt accounting
differences (release on failure, settle on unusable answer).

(e) The model id travels from settings through `Config.ModelID` into
`GenerateEditorial`. No model literal lives in non-test code. The passthrough

live-tagged probe only.

(f) Budget reserves before the call and a refused reservation reaches no model

(g) Dangling spans drop with a log line and never store. This is pinned with
spans at offsets 400, 45, and 90..91 against 40 words, plus a log assertion
