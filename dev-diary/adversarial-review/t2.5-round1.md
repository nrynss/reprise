## Headline ruling

The done criterion reads: on all three fixture sessions, measured offsets
agree with the recorder offsets within 40 ms. No fixture exists
(`testdata/sessions` is absent, T0.5 owns fixtures and is still running), so
`TestFixtureSessions` skips at `fixture_test.go:88` and the suite is green
without measuring anything. A green suite that measured nothing is not a met
criterion. This alone would be a recorded limit with remeasure owed, except
the handoff and the code admit a sharper defect that is fixable now, inside
`owns`, without waiting for T0.5: any other layout skips silently
(`fixture_test.go:24`, `fixture_test.go:30`, handoff lines 74 to 78). The
reviewer proved a directory holding `provider.wav`, `offsets.json`, and a
misnamed stem file SKIPs green with only a `-v` log line. A wrong-layout
fixture, including a typo the fixture owner makes while satisfying this
task's own contract, therefore passes silently. That converts "criterion
unproven yet" into "criterion unprovable by this suite even when fixtures
land", because the suite cannot distinguish three measured sessions from
three skipped directories. The T3.1 precedent does not apply: there the
measurement ran on generated input and only the liveness owed a rerun. Here
the driver code path that must carry the criterion (`checkFixtureSession`:
WAV decode, `offsets.json` parse, resample, channel mapping, `Align`) runs
zero times anywhere in the suite. The synthetic end to end test
(`align_test.go:229`) mirrors the math but never touches the driver, so the
driver ships untested.

Ruling: REMEDIATE, not approve-with-limit. The remediator stays inside
`internal/align/` and owes: (a) a synthetic in-test layout proving the
driver measures, not just skips (write `user.wav`, `host.wav`, stereo
`provider.wav`, `offsets.json` to `t.TempDir()` with known chirps and call
`checkFixtureSession`; plus a drifted variant that must fail the 40 ms
check, which the reviewer prototyped and measured at exactly 50.0 ms drift);
(b) a loud failure when a session directory exists but the layout is wrong
(missing stem files inside an existing directory must fail, not skip; the
top-level missing-root skip may stay); (c) an audible ran-count assertion so
three measured sessions are pinned, not assumed. The remaining debt, running
the driver against the three real T0.5 fixtures when they land, is then a
legitimate remeasure owed, and the remediator states it as such.
