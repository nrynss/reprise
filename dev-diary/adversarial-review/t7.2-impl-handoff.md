## What it built

The binary shares one Gemini client across all model passes,
registers every pipeline and settle kind, and settles each mint
through session end plus the scheduled sweep.

`main.go` constructs the Gemini client once from the file credential
and shares it across editorial, chapters, cover, and marking, with
every model id from settings. It registers all eight kinds with paid
passes non-idempotent, wraps the session end handler to start one
reconcile job per recorded close, runs the abandoned sweep every five
minutes with an immediate boot pass, fails episodes left with
interrupted paid jobs after runner recovery, and wires the episode,
session end, and threads handlers per the landed T7.1 contract.

`internal/broker/settle.go` (new) keeps mint linkage in a
broker-owned table, rebuilds reconciler input for the end path, lists
sweep candidates with a recorded provider close only, and adapts the
sessions client to the reader and ender seams with ceiling-rounded
durations. `internal/gemini/` gains chapter, image, commitment, and
resolution calls over the shared generate path. Tests pin kinds and
shared construction, settle exactly once, restart failing the paid
episode, and cover plus marking offline.

## Surprises

The cost store reservation TTL defaults below the session cap, so
holds evaporate mid session. The wiring sets the TTL past cap plus
sweep margin. The batch client returns no entities, phrases, or
summary, so the analysis adapter maps words faithfully and leaves
those empty until a provider adapter asks for the features.
