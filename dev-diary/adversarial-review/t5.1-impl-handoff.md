## What it built

`internal/export/` bundles one finished episode for upload. Seven files,
all new.

* `export.go`. Package doc, the 1920 by 1080 frame constants, the chapter
  rules, the blob content types, one sentinel per failure, and the `Word`
  plus `Chapter` input shapes on the episode clock.
* `captions.go`. `ToCaptionWords` validates rendered words and converts
  them for the library captioner. `SRT` and `WebVTT` group through that
  call, so this package writes neither format itself and both files share
  timings.
* `description.go`. `Stamp` renders the form stamps (`0:00`, `1:30`,
  `1:01:01`). `ValidateChapters` enforces the form rules. The first
  chapter opens at zero, at least three exist, titles stay non-blank,
  starts rise strictly, and every chapter lasts ten seconds against the
  render length. `Description` prints the show notes first, then the
  timestamped chapter lines.
* `video.go`. `BuildVideo` draws the waveform over the still cover at
  1920 by 1080 through the library waveform call, with the AAC stream
  copied, never re-encoded. `ProbeVideo` measures a built video with
  ffprobe for frame size, audio presence and codec, and duration.
* `cover.go`. `CoverSize` reads PNG dimensions without a full decode.
  `CheckCoverSquare` rejects non-square art before bundling.

## Pins, all measured on bytes

* A 35 second generated AAC tone plus a generated 1024 square panel build
  the video. `ProbeVideo` asserts 1920 by 1080, an AAC audio stream, and
  a duration within 150 ms of the probed render length. The window covers
  the priming samples a copied lossy stream adds.
* A strict test parser validates both caption files block by block. It
  checks numbering, timing shape, non-empty text, monotonic non-overlapping
  cues, first cue at zero, and last cue end at the last word end. A second
  test asserts SRT and WebVTT carry identical cue timings.
* The description test extracts chapter lines from a built description
  and asserts the notes lead, the first line reads `0:00`, at least three
  lines exist, and every span reaches ten seconds. A table test asserts
  each rejection maps to its sentinel.
* Mutations were checked by reading the pins. Moving the first chapter
  start off zero fails validation. Shuffling one word fails conversion.
  Rectangles fail the square check.

## What surprised it

The library waveform call copies the audio stream, so the output must
name a container that carries AAC. MP4 qualifies, and the AAC render
already lives in MP4, so no re-encode step exists. The 150 ms duration
window is container rounding plus codec priming, not a wall-clock wait.
The library WebVTT writer numbers its cues, so the test parser expects
numbers there exactly as in SRT.

## Contract changes

For wiring. Read rendered words and the chapters JSON from the analysis
rows, the AAC blob id from the renders row, and the square file from the
covers row. Feed words, chapters, notes, and the render length into this
package. Persist the five outputs under the content types in `export.go`.
The media store already accepts both caption types, so no store change is
needed. Episodes under thirty seconds cannot satisfy the chapter rules,
and `Description` reports `ErrChapters` for those instead of printing
markers the form would ignore.

No library issue arose. Keel `v0.3.0` carried caption, waveform, and
ffmpeg as recorded.
