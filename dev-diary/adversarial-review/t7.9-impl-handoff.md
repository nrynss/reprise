## What it built

The completion answer and episode detail report the last transcript
pass outcome, and an empty pass fails its episode.

`internal/episode/outcome.go` (new) reads the latest stamped job of
one kind from the shared job rows, scoped to the owner, with the
kind arriving through config so processes without a runner still
serve. The chain tail fails the episode on run error or zero landed
words, so the job record and the episode agree. Ensure paths treat
any prior stamped pass, terminal or not, as covering. The completion
answer carries `transcript_outcome` with job id, status, and error
text. Detail carries the same outcome beside proposals. A repeat
completion on a failed episode answers 200 with the outcome.
