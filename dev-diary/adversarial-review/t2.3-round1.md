## Findings

### F1: an expired lease parks a session in review forever and its artifacts never finish

Severity: H
Where: `internal/broker/reconcile.go:601-602` (a failed lease close returns review), `internal/broker/reconcile.go:624-637` (the resume switch sends every non-closed and non-reconciled lease to review)

What: A lease expires at mint plus cap, and expiry is terminal. Any session that runs near its cap reaches the close with an expired lease, because the close runs after the session end plus the provider read and the settle. The run settles money once, then the close fails and the result asks for review. Marking settled never runs, so the session row never learns its duration and the stereo recording never persists, while the provider URLs expire unrecorded. Every retry inspects the same terminal expired state and reviews again, so no retry can clear it. I proved this with a real lease manager and a short cap against an in-cap provider duration of 10 seconds under an 1800 second token cap. The first run settled exactly once and asked for review. The second run asked for review again. Connected seconds stayed zero. No over cap alert fired, because the run never reaches the artifact tail. The run that hit the expiry knew the provider numbers and the settle outcome, so nothing about it was ambiguous. The ambiguous resume policy does not cover it.

Pin: Build a reconciler over the real cost store, a real lease manager with a 150 ms cap, the real media store, and a stub reader that serves `{"id":"prov-short","duration_seconds":10,"recording_url":"...","timeline_url":"..."}` through the real parser. Open a lease, sleep past the cap, then call Reconcile with a token cap of 1800. Assert the result does not need review, the session row reads 10 connected seconds, and a recording media id persists. This fails now at the first assertion with `NeedsReview: true` and the detail `hold settled to $0.0125, lease ... did not close ... in state expired`. I ran this shape in the worktree and watched it fail, then deleted the probe file.

Mutation: Send expired leases back to review in both the close path and the resume switch. In other words, delete the remediator's expired-state completion branch. The pin fails again at the NeedsReview assertion, so the pin measures that branch.

### F2: the over cap alert fires again on every idempotent retry

Mutation: Remove the remediator's once-only guard around the alert, so the tail alerts on every call again. The pin fails with two alerts, so the pin measures that guard.
