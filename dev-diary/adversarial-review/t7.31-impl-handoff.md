## What it built

The boot syncs the season catalog from the season directory under the
configured data directory and refuses the boot with the file key on a
validation failure. The seed hook registers no job kinds and mounts one
route, `GET /api/welcome`, behind the spend gate and the guest
middleware. That route re-syncs the catalog, copies it to the guest
once through the existing receipt, and answers the mode plus the teaser
episode. Owners receive no copy and read the catalog. The welcome page
renders the live answer and keeps the query string fixtures where no
backend answers, so the scripted proofs still run against the static
build. A live render plays to its end. Generated tone keeps the thirty
second cap.

Catalog import now stores a render row beside every audio sibling and
names it in the render link row, in the same transaction. Copies mint
their own render row under the new owner, keep the shared blob ids, and
link their own words to their own render. A rows only file stores
neither. Drop removes the copy render and link through the existing
cascade and keeps the catalog audio.

## What surprised it

The hook test in finish_test.go mounts every feature with an empty
wiring and expects success with nothing registered. The seed mount
therefore skips on an empty wiring and syncs only on the real boot.
The real boot always passes the stores, so the skip changes no
production path.

A one episode catalog cannot feed the callback selector, because
recurring names need two episodes and the planted row needs an agreeing
candidate. It feeds the host opening directly instead, through the
oldest unused planted callback. The wiring test pins the greeting.

The svelte 4 scan reads `Map.get` as store reactivity, the same shape
an earlier fix removed from the editor draft. The tone cache is now a
plain record.
