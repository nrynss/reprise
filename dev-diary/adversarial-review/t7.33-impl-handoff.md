## What surprised me

  standalone. Playwright resolves relative navigation against the started
  preview server. No fix was needed there.
- This workstation cannot launch WebKit. The host carries libicu 78 and
  libxml2 16, while the installed WebKit build wants libicu 74, libxml2,
  and libflite1. No sudo exists here, so the system packages cannot be
  installed. Chromium runs every suite. CI installs both browsers with
  dependencies, so it covers WebKit.
- `go list ./...` works here. The probe packages moved into their own
  module, so no Go scoping was needed.
