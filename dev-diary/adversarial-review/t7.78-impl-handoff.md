## What was built

`assemblyai.CreateRequest` carries `EntityDetection` and `AutoHighlights`, sent as `entity_detection` and `auto_highlights` with `omitempty` so plain transcription omits both. `Transcript` carries `Entities` and `Phrases`, parsed from `entities` and `auto_highlights_result.results` with millisecond spans. `batchTranscriber.Create` sets both flags for the analysis pass only. The result maps both into the analysis result, which the run stores as mentions. `analysis.Estimate` and the settle price use the combined rate. The edit pass builds its creation call with audio URL and keyterms only, so both keys stay absent.
