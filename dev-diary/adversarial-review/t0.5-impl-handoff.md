# T0.5 implementation handoff

Three short live sessions from generated speech, committed under
`testdata/sessions/`. Final commit `828dd44791f353fd4d54c2a3b9ae420d9298685f`
on branch `task/t0.5` in worktree `t0.5-impl`. Worktree clean.

## What was recorded

Each session streamed espeak-ng 1.51 clips from Ubuntu 24.04 in Docker.
No real voice appears anywhere. The runner reused the reviewed probe
framing and lived outside the repo, so no runner code was committed.
The artifacts plus the README command are the deliverable.

- `steady/`: two lines back to back with no gaps. Both transcripts
  read back exactly. Duration 18.11 seconds.
- `pauses/`: four seconds before the first line, six seconds between
  lines, three seconds before ending. Both transcripts read back
  exactly. Duration 30.38 seconds.
- `bargein/`: a trigger line asks for a longer story, then the barge-in
  line cuts in 2.5 seconds after the story audio starts. The timeline
  marks the story turn interrupted and the barge-in turn completed.
  Duration 25.24 seconds.

Per session: the user stems as generated, the provider stereo
recording, the event log with local clock times, and the timeline and
metadata records. The README lists every file with ffprobe values and
SHA-256, plus the recreate command. Every hash was recomputed with
`sha256sum` after staging.

## Spend accounting

Three tokens minted, one per session, each capped at 120 seconds.
Connected seconds from `session.ended`: 18.11 plus 30.38 plus 25.24,
total 73.73 seconds. Cost at 4.50 dollars per hour is about 9 cents.
The Sessions API agreed within half a second on each session. All
three sessions returned 204 on DELETE and list as gone. The per run
ceiling of three times 120 seconds is 45 cents, far under the
reviewed probe per run ceiling.

## Offline proof

Picked a P3 shaped read on `steady/`: decoded `events.json` and both
user stems with `ffprobe` and a small script, with no network. Output:
1168 events with the first clock stamp, both user transcripts exact,
both stems as mono PCM, the recording as stereo Opus, and three turns
with greeting plus two speech triggers. The same files serve the pause
and barge-in reads.

## Gate result

`npm ci` in `web/`, then `./tools/check.sh`: exit 0, all checks pass.
No Go files were added, so gofmt and vet see no new code. The known
consumer names hit on the tracked mockup file did not appear in this
worktree run. The gate passed clean with no exception to record.

## Surprises

- Artifact URLs need a short wait after `session.ended`. The first run
  fetched at once and found zero artifacts. A ten second poll fixed it.
- The pauses session grew a fourth timeline turn. The host added a
  closing remark after the second reply, carried as a greeting trigger.
- The barge-in needed a story prompt, not a short reply prompt. The
  one sentence host finished before the cut arrived, so the prompt now
  asks for a longer story and the cut lands mid reply.
