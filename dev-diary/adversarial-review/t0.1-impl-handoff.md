## What surprised us

- `go vet ./...` and `go test ./...` walk `web/node_modules`, which carries
  third-party Go files (the `flatted` package). The gate filters the package
  list through `go list ./... | grep -v /web/`.
- `adapter-static` with `fallback: 'index.html'` overwrites the prerendered
  root page, leaving a client-only shell. Changed to `fallback: 'fallback.html'`
  so `/` serves prerendered content and unknown paths serve the shell.
- The distroless runtime needs an explicit `WORKDIR` and an absolute
  entrypoint with an absolute `-web` path. With a relative default and no
  working directory, every static request 404'd while `/healthz` worked.
- `eslint-plugin-svelte` v3 has no rule against `export let`. The mechanical
  leakage guard lives in `check.sh`, not ESLint.
- The consumer-name scan caught the gate script's own documentation. The
  script exempts itself (and `.gitignore`, which must name what it excludes)
  from both scans.
