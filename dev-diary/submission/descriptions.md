# Descriptions draft

## Title

Reprise: a personal podcast that remembers

## Short description

Reprise turns a conversation into a listenable episode. The host asks follow-ups and remembers what you said last time.

## Long description

Reprise is a personal podcast. You talk, a host asks, and the talk becomes an episode with a cold open, chapters, and show notes.

The beat that sells it is memory across episodes. Mention something you dread in episode one. The host opens a later episode by asking whether it happened. Nobody needs the feature explained after hearing that.

The app records both sides locally as separate stems. The model proposes every cut and you dispose of every cut. Every episode stays private by default, and publishing takes one explicit action.

The live app runs at `https://reprise.nryn.dev`. Scripted verification minted sessions, streamed speech, and closed explicitly with provider confirmed closes.
